微信公众号图片排版助手隐私政策

生效日期：2026 年 8 月 2 日

我们处理的数据

扩展仅处理用户主动选择的图片，以及用户自行填写的 GitHub 仓库配置和 GitHub 访问令牌。扩展不会收集浏览历史、位置、通讯、财务信息或广告标识符。

处理目的和方式

GitHub 仓库配置和访问令牌保存在用户设备的浏览器本地存储中。只有当用户主动上传图片时，扩展才会将所选图片和访问令牌发送到 api.github.com，用于把图片保存到用户指定的 GitHub 仓库。排版和预览在用户设备本地完成。

共享、出售和保留

开发者不会接收、出售或出于扩展单一用途之外的目的共享用户数据。发送到 GitHub 的数据由用户自己的 GitHub 账号及 GitHub 的条款和隐私政策管理。清除扩展数据或卸载扩展会删除保存在浏览器本地的数据。

数据安全与用户选择

扩展通过 HTTPS 与 GitHub API 通信。用户可以不填写 GitHub 配置而使用本地图片排版功能，也可以随时在扩展中更改或清除配置。

政策更新

若扩展的数据处理方式发生重大变化，本页面会同步更新，并在适用时通过 Chrome 应用商店版本说明告知用户。

联系我们

如对本隐私政策有疑问，请通过项目的 GitHub 仓库提交 Issue：github.com/cooker/wx-mp-article/issues。
